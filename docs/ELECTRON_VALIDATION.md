# Electron 1.3.0 验证记录

日期：2026-11-05。验证使用 Windows 11 x64、Node.js 24.16、Electron 45.2.1、Vue 3.5.44、Element Plus 2.14.7 和 Python 3.12。

## 已验证

- 22 项原文件处理核心测试通过。
- 17 项 JSON-lines 服务测试通过：旧库结构、人工字段保留、审核、生成计划失效、取消、备份、UTF-8 子进程协议与资料库锁。
- 27 项文件名解析与年月测试通过：作者 / 社团拆分、汉化组规范化、标签、异常括号保留、已有 XML 优先、月份写入和旧资料兼容。
- 18 项导入与批量操作测试通过：预览不写库、目录重叠去重、只导入勾选项、重扫不补入未选子目录、批量作者类型、保留人工资料、移除后重扫跳过、显式恢复、源变化、预览过期与取消。
- 17 项元数据规则测试通过：27 项定义映射、多角色独立标签、标准字段往返、真实系列不同作者、无系列作品防误合并、年龄与日历校验、中文原创与未知译者区分、颜色未知值、多个来源 URL、旧库备份迁移与人工字段保留、规范字段显式清空不复活。
- 9 项 Node 进程通信测试通过：非法参数、新导入与批量方法、UTF-8 分片、请求关联、进度、取消、异常 stdout 和后台退出。
- Vue TypeScript 检查与 Vite 生产构建通过。
- 实际 Windows Electron 窗口启动成功，preload、Vue、Element Plus 和本地文件服务连接正常。
- Electron 窗口完整流程通过：空状态 → 展开目录树并勾选多个子目录 → 预览解析结果 → 统一作者和类型 → 确认入库 → 重扫仍排除未选相邻作品 → 展开资料分组，编辑作品名、系列与系列译名、期号、卷号、总数、日期与来源链接 → 切换全年龄 / R18 验证修正状态 → 保存与审核 → 预览翻页、换封面并重新审核 → 校对标准 XML 与自定义标签 → 生成并校验 CBZ → 批量修改撤销审核 → 移出、重扫、显式恢复与备份。
- 流程结束确认源图片原字节保留、成品存在、数据库状态为 packaged、封面页索引正确、备份存在。
- 隔离渲染进程内没有 window.require / window.process，任意方法请求被拒绝。
- 1180×800 小窗口下审核栏及导入确认按钮保持可见，页面、资料和 XML 分区独立滚动。

核心与服务使用 Python 标准库；Electron 便携包未包含 Qt。内置后台为 PyInstaller console 模式，由 Electron 隐藏启动，不依赖系统 Python。

本次通过 npm run test:desktop 执行真实 Electron 流程，启用正常进程隔离与渲染沙箱，没有关闭这些保护；设置 COMIC_MANAGE_TEST_SHOW=1 验证实际绘制的窗口。测试入口为 electron/smoke.cjs，临时合成样本与结果位于忽略的 build/ 目录，不使用用户漫画数据。
