# v1 验证记录

验证日期：2026-11-02。使用合成图片、临时目录和测试 CBZ，不访问用户真实漫画或 NAS。

## 已完成

- Windows 11 x64、Python 3.12.12、PySide6 Essentials 6.10.2：`unittest` 31 项全部通过（22 项核心、9 项 Qt 界面流程）。
- 实际 Qt 流程：载入图片预览 → 编辑 → 勾选审核 → 审核通过 → 确认生成计划 → 后台生成 CBZ → SQLite 标记校验成功。
- 搜索中日文标题、多作者；更换封面与 XML 预览；未勾选审核时拒绝通过。
- 中文路径、自然页序、源文件字节不变、CBZ 附件保留、备份恢复读取。
- 已存在目标拒绝覆盖；源文件在审核后、预览后及打包过程中变化时拒绝生成。
- 取消 / 校验失败不发布成品并清理临时文件；损坏、重复条目、危险路径和 XML DTD 被拒绝。
- PyInstaller 6.19.0 生成 Windows 64 位便携包；通过 Windows 原生窗口检查，确认 exe 启动、中文文字、初始界面与关闭正常。
- 构建脚本固定本次 Python 与系统 DLL 搜索目录，避免 PATH 中其他软件的 Python / ICU DLL 混入。

## 尚需用户环境验收

- 实际 NAS / SMB 读写、断网恢复、磁盘空间不足和大规模库的性能。
- 实际 Kavita 版本中的入库、双标题搜索和封面识别。
- Windows 10、其他 DPI、其他语言系统与未签名 exe 的分发体验。
- Python 3.11 / 3.13 的 CI 检查以 GitHub Actions 的实际结果为准。

本次校验确认打包字节完整性，不代表漫画来源的画质、页序命名或元数据一定正确。v1 保留人工确认步骤与原始文件。
